# TorrServer Bunny — простая инструкция на русском

**🇷🇺 Русский** · [🇬🇧 English](README.en.md) · [🇳🇱 Nederlands](README.nl.md) · [Главная страница проекта](../README.md)

**Что это?** Свой TorrServer для Lampa на базе [Bunny Magic Containers](https://bunny.net/magic-containers/) — без аренды VPS. В основе лежит оригинальный открытый проект [TorrServer от YouROK](https://github.com/YouROK/TorrServer).

**Самое главное:** установил один раз → вписал HTTPS-адрес в Lampa → перед фильмом нажал **Start** → после просмотра **Stop**. Настройки и адрес сохраняются.

> **Реальный статус:** 2 ноября 2026 года удалось создать приложение в Bunny, получить статус `active` и настоящий HTTPS CDN-адрес. Но просмотр на физическом Samsung Tizen, соединения с торрент-пирами и автоматическое отключение через GitHub Actions пока не подтверждены отдельным реальным испытанием. Работа каждого торрента или формата видео не гарантируется.

## 1. Что потребуется

- Аккаунт [bunny.net](https://dash.bunny.net/) с Magic Containers и **Bunny account API key**. Ключ храните в секрете.
- Компьютер **Mac или Linux** с `python3` и `curl`; Docker и VPS для обычной установки не требуются.
- Lampa на телевизоре или другом совместимом устройстве с возможностью указать TorrServer.
- Интернет и торрент, на просмотр и распространение которого у вас есть права.

Приложение использует общедоступный образ `ghcr.io/vbrekher/torrserver-bunny:main`. Если Bunny не сможет проверить образ через GHCR, установщик остановится до платного создания контейнера.

## 2. Установка — только один раз

Откройте **Терминал** на Mac или Linux, скопируйте команду целиком:

```bash
curl -fsSL --retry 3 \
  https://raw.githubusercontent.com/vbrekher/TorrServer-bunny/master/install-bunny.sh \
  -o /tmp/install-torrserver-bunny.sh \
  && sh /tmp/install-torrserver-bunny.sh
```

Установщик задаст вопросы:

| Вопрос | Что вводить |
| --- | --- |
| **Bunny account API key** | Ваш секретный API-ключ Bunny. Ввод скрыт. Никому не отправляйте ключ, даже в переписке. |
| **Select region** | Выберите регион, например `AMS` (Амстердам) или `DE` (Германия). |
| **TorrServer username** | Нажмите Enter для `lampa` или впишите свой логин. |
| **Expose BitTorrent TCP/UDP peer port via Anycast?** | `N` — начать без дополнительного платного IP; `y` — добавить платный IPv4 для входящих подключений торрент-пиров. |
| **Confirm** | Введите `CREATE` **один раз**, если согласны на создание платных ресурсов Bunny. |

Установщик создаёт одно приложение Magic Containers в одном регионе, **постоянный том настроек 1 ГБ** и **HTTPS CDN-адрес**. Если выбрали `y`, отдельно добавит платный BitTorrent Anycast IPv4. Пароль TorrServer создаётся автоматически и сохраняется **локально** в защищённом файле.

**Важно:** если сервер уже был создан, **не повторяйте установку с нуля**. Используйте команды из пункта 4.

## 3. Как подключить Lampa

После установки посмотрите состояние:

```bash
~/.local/bin/torrserver-bunny status
```

Найдите строку **`TorrServer HTTPS CDN URL:`** и проверьте, что состояние `State: active`. Пример правильного адреса: `https://mc-example.bunny.run`. Это **только пример**, а не адрес вашего сервера.

Чтобы узнать свой пароль на собственном компьютере:

```bash
~/.local/bin/torrserver-bunny status --show-credentials
```

Откройте **Lampa → Настройки → TorrServer** (в разных версиях пункты могут называться немного иначе):

| Поле Lampa | Что указать |
| --- | --- |
| Сервер / URL | Ваш **HTTPS CDN-домен** из команды `status` |
| Логин | Например, `lampa`, либо выбранный вами |
| Пароль | Ваш пароль, показанный установщиком или `--show-credentials` |

**Не перепутайте адреса.** Адрес вида `https://109.224.231.152:32000` — **не для Lampa**! Порт `32000` нужен для торрент-пиров. В Lampa нужен HTTPS **домен CDN**, без `:32000`.

Если HTTPS-адрес пока не появился, откройте **Bunny Dashboard → Magic Containers → ваше приложение → Endpoints** и найдите `torrserver-https`. При необходимости вручную сохраните настоящий домен:

```bash
~/.local/bin/torrserver-bunny set-url https://ВАШ-РЕАЛЬНЫЙ-CDN-ДОМЕН
```

Можно сначала проверить HTTPS-адрес в браузере, затем попробовать **один свободно распространяемый, разрешённый торрент**. Статус `active` ещё **не доказывает**, что воспроизведение работает на конкретном телевизоре Samsung.

## 4. Самое простое: запускать, смотреть, выключать

Каждый раз заново устанавливать сервер или создавать новое приложение Bunny **не нужно**.

| Что нужно сделать | Команда в Терминале |
| --- | --- |
| **Включить** TorrServer перед фильмом | `~/.local/bin/torrserver-bunny start` |
| **Узнать состояние** и адрес | `~/.local/bin/torrserver-bunny status` |
| **Выключить** после фильма | `~/.local/bin/torrserver-bunny stop` |
| **Посмотреть пароль** на своём Mac | `~/.local/bin/torrserver-bunny status --show-credentials` |

Команда `start` запускает **тот же самый** контейнер, `stop` останавливает вычислительные ресурсы, а `status` проверяет актуальное состояние. Запуск происходит не мгновенно: после `start` проверьте `status`, пока не появится `active`.

**Lampa сама не включает остановленный контейнер.** Сначала `start` в Терминале, затем просмотр на телевизоре. Команда `stop` **не удаляет** приложение и настройки. HTTPS-адрес должен сохраниться. Однако постоянный том и выделенный Anycast IP могут тарифицироваться даже после `stop`.

## 5. Сколько стоит один Blu-ray-фильм размером 50 ГБ?

Посчитаем **пример**, а не обещанную цену: один зритель, **50 ГБ исходящего видеотрафика** в Европе или Северной Америке, фильм длится **3 часа**. Для расчёта предположим **1 ГБ оплачиваемой RAM** и полную загрузку **1 ядра CPU** все три часа (реальная нагрузка может быть другой).

| За что платим | Расчёт | Сумма |
| --- | ---: | ---: |
| Передача 50 ГБ видео | 50 × $0,01/ГБ | **$0,50** |
| Работа CPU (условный пример) | 3 часа × 1 ядро × $0,02 | **$0,06** |
| Оперативная память (условный пример) | 3 часа × 1 ГБ × $0,005 | **$0,015** |
| **Ориентир за один просмотр** | **Трафик + CPU + RAM** | **$0,575 ≈ $0,58** |
| Постоянное хранилище настроек | 1 ГБ × $0,10/месяц | **$0,10/месяц** |
| Anycast IPv4 (если выбран `y`) | $2/месяц, поминутное начисление | **около $2 за полный месяц** |

**Если за месяц посмотреть только один такой фильм**, а том и Anycast IP оставить выделенными на все 30 дней, примерная сумма будет:

- **Без Anycast:** $0,575 + $0,10 ≈ **$0,68 за месяц**.
- **С Anycast:** $0,575 + $0,10 + $2 ≈ **$2,68 за месяц**.

**$2 за Anycast — не плата за каждый фильм.** Это стоимость выделенного IP за полный месяц; если фильмов несколько, месячная плата за IP распределяется между ними. Если IP выделен только часть месяца, начисление пропорционально времени.

**Что не вошло в пример:** дополнительные исходящие данные торрент-пирам (раздача / seeding), повторы и перемотки, дополнительные расходы на CDN/доставку в зависимости от конфигурации, другие регионы, налоги, прочие услуги Bunny и минимальная сумма счёта аккаунта. Торрент с размером файла 50 ГБ **не гарантирует** ровно 50 ГБ оплачиваемого трафика. Фактические расходы смотрите в панели Bunny.

Официальные тарифы (проверены **2 ноября 2026 года**): [Magic Containers](https://bunny.net/magic-containers/) · [Bunny CDN](https://bunny.net/pricing/cdn/).

## 6. Как сделать автоматическое выключение через 60 минут

По умолчанию сервер выключается вручную. В проекте предусмотрен дополнительный **GitHub Actions watchdog**: примерно каждые 10 минут проверяет активность и отправляет команду остановки, если передачи видео не было **не менее 60 минут**.

Для включения нужны установленный и авторизованный [GitHub CLI](https://cli.github.com/) (`gh`), **ваш собственный репозиторий или форк** с файлом `.github/workflows/idle-watchdog.yml`, а также право создавать GitHub Actions secrets.

```bash
~/.local/bin/torrserver-bunny enable-github-watchdog --repo ВАШ-АККАУН/ВАШ-РЕПОЗИТОРИЙ
```

Проверьте содержимое workflow и подтвердите `ENABLE`, только если доверяете репозиторию. Программа запишет секретные данные, включая Bunny API key, в GitHub Actions secrets **вашего** репозитория. Не передавайте ключ через чужие репозитории.

**Ограничение:** запланированные GitHub Actions могут запускаться с задержкой или не запускаться; точного выключения по таймеру и гарантии прекращения расходов нет. Watchdog не запускает сервер при открытии Lampa.

## 7. Если что-то не работает

| Проблема | Что делать |
| --- | --- |
| Сервер `active`, но фильм не идёт | Проверьте HTTPS CDN-домен и логин/пароль, попробуйте легальный тестовый торрент, посмотрите логи контейнера Bunny. Работа с пирами и совместимость кодека с Samsung проверяются отдельно. |
| Показан `https://IP:32000` | Это **неправильный** Anycast-адрес. Обновите CLI и выполните `status`, чтобы получить HTTPS CDN. |
| Нет HTTPS-адреса | Найдите `torrserver-https` в Bunny Dashboard. Не создавайте новое приложение. |
| `Already configured` | Сервер уже настроен. Пользуйтесь `start`, `status`, `stop`; повторная установка не нужна. |
| `HTTP 500` при создании | Не нажимайте `CREATE` повторно вслепую. Выполните `~/.local/bin/torrserver-bunny doctor`, проверьте панель Bunny; при необходимости обратитесь в поддержку. |
| Ошибка GHCR | Убедитесь, что Docker-образ доступен и настроен GHCR-реестр с **числовым ID** Bunny. |

Чтобы **обновить установленную программу**, не создавая новый сервер, можно скачать установщик с параметром `status`:

```bash
curl -fsSL --retry 3 \
  https://raw.githubusercontent.com/vbrekher/TorrServer-bunny/master/install-bunny.sh \
  -o /tmp/install-torrserver-bunny.sh \
  && sh /tmp/install-torrserver-bunny.sh status
```
